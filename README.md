# Permis B – Ma théorie (Wallonie)

Appli personnelle d'étude de la théorie du permis B : cours, quiz adaptatifs, examens blancs chronométrés, favoris, points et séries, rappel quotidien.

**Installer sur Android :** télécharger [PermisB.apk](../../releases/download/appli/PermisB.apk) depuis le téléphone, puis l'ouvrir.

L'appli est construite automatiquement par GitHub Actions à chaque modification (dossier `www/` = l'appli, `android/` = l'emballage Capacitor).
